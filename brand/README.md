字形はアウトライン化したSVGです。参照フォントの有無によって日本語が置換されないよう、パスを使って保持しています。背景は透過（アイコンは濃紺の角丸背景付き）。

**現在のステータス：デザイン採用候補。** 10・15mm等の印刷品質確認を終えるまで「最終承認済み」とは呼びません。

## コンセプト

`>こぴみずむ_` を基本形とし、`>` はコマンド入力の始まり、末尾の `_` は入力カーソルを表します。アイコンの `>こ_` はメインロゴから切り出した意匠です。

- ピンク：`#F34A86`（`>こぴ`）
- ブルー：`#2381F5`（`みずむ_`）
- 濃紺：`#152B4B`（英字・アイコン背景）
- 表示名：日本語は **こぴみずむ**、英字は **COPIMISM**。元となった「Kopimism」とサークル独自の表記は区別します。

## 使用上の注意

- アスペクト比を変えて引き伸ばさず、文字・装飾を削除したり、配色や配置を勝手に変更しないでください。
- ロゴ周囲に適切な余白を取り、他のロゴや文章で文字を覆わないでください。
- モノクロ印刷では専用のモノクロ版を利用し、カラー版の単純グレースケール化は避けてください。
- 小さいサイズでは可読性が変わります。最終的な最小使用サイズは実寸印刷検証後に定義します。
- 利用するサイトや作品がこぴみずむの公式・公認・提携であると誤認させないでください。
